Z-Score Mathematical Formulation

The statistical engine relies on standard deviation scaling over a trailing 14-record sliding window (μ14 and σ14):

Z = (x - μ) / σ
  • |Z| ≤ 2.2: Normal random variation (~97% confidence interval).
  • 2.2 < |Z| ≤ 3.0: WARNING (Demand surge or operational dip).
  • |Z| > 3.0: CRITICAL (Extremely rare, 99.7% 3-sigma outlier).

Windowed SQL View Architecture

To compute sample standard deviation without a native SQLite function, we utilize the variance expansion formula:

Var(X) = E[X²] - (E[X])²
StdDev(X) = SQRT(MAX(0, Var(X)))

Partitioning by SKU (PARTITION BY item ORDER BY id) ensures each product maintains independent baseline statistics without cross-item contamination.
